# Security and privacy reports

Do not post tokens, private avatars, network credentials, tracking profiles or personal recordings in public issues. For a security vulnerability, use GitHub's private vulnerability reporting feature if enabled, or contact the maintainer through the public GitHub profile to arrange a private report. Do not publish exploit details while arranging a report.

The application loads Unity asset bundles and communicates with local tracking/streaming software. Import packages only from sources you trust. Use loopback for local bridges where possible; a phone may require a restricted LAN firewall rule. The application does not automatically install firewall rules or camera drivers.

The current maintained line is the latest published alpha. Reports should state the release, operating system and steps to reproduce, with personal data removed.
