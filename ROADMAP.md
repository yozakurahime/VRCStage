# VRCStage roadmap

The immediate goal is a reliable first stream with an existing VRChat avatar, with as little setup as possible. Items below are planned work, not shipped promises or dates.

## Next: first-stream experience

- Turn the new **Começar** hub into a guided setup with input diagnostics and recovery steps.
- Add English UI and maintain Brazilian Portuguese documentation.
- Offer live-ready camera/light/background presets and clear save/load behavior.
- Improve automatic expression mapping with a report of measured, estimated and unsupported signals.
- Add a repeatable performance baseline with face, hands, physics and video output enabled together.

## Avatar reliability

- Expand controller/layer and exported constraint coverage with redistributable test fixtures.
- Improve hair anchoring, collider behavior and pose/tracking blending.
- Report unsupported build/plugin results clearly during export.
- Provide compatibility examples for supported shader pipelines and publicly licensed avatars.

## Studio and creator tools

- Camera/lighting preset library, photo workflows and output profiles.
- More robust desktop movement, orbit collision and pose transitions.
- Input ownership indicators for VR, face, Leap, webcam and animation sources.
- Better body-proportion calibration and hand/forearm stability.

## Community and distribution

- Reproducible public build instructions and independent clean-clone checks.
- Small public regression avatars/scenes with clear licenses.
- Release notes, issue triage and a documented compatibility matrix.
- Review installer/update/signing options after the first alpha is validated.

No roadmap item promises complete VRChat parity, all Unified Expressions from ARKit, or redistribution of third-party commercial avatar/motion content.
